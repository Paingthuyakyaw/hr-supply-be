# n8n Local Onboarding Workflow (Option 2)

This guide connects local `n8n` with `createEmployee` in this backend.

## 1) Start n8n locally

```bash
npm run n8n:local
```

Open `http://localhost:5678`.

## 2) Create workflow in n8n

Create a workflow with these nodes in order:

1. `Webhook` node
   - HTTP Method: `POST`
   - Path: `employee-created`
2. `IF` node (validate secret)
   - Condition: header `x-onboarding-secret` equals your shared secret
3. `Send Email` node
   - To: `={{$json.email}}`
   - Subject: `Welcome to the company`
   - Body should include:
     - `{{$json.fullName}}`
     - `{{$json.setupLink}}`
     - `{{$json.tempPassword}}` (only when generated by backend)
4. `Slack` node (or `HTTP Request` to Slack webhook)
   - Send summary to HR channel
5. `Telegram` node (optional)
   - Send summary to HR/admin group
6. `Wait` node
   - Resume At: `={{new Date(new Date($json.dateJoined).getTime() + ($json.probationDays * 24 * 60 * 60 * 1000)).toISOString()}}`
7. `Slack`/`Telegram` reminder node
   - Send probation reminder

## 3) Backend env configuration

Add these to your `.env`:

```env
N8N_ONBOARDING_WEBHOOK_URL=http://localhost:5678/webhook/employee-created
N8N_ONBOARDING_SECRET=replace-with-a-strong-shared-secret
ONBOARDING_PROBATION_DAYS=90
ONBOARDING_WEBHOOK_TIMEOUT_MS=5000
ONBOARDING_SETUP_LINK_BASE_URL=http://localhost:5173/setup-account
```

## 4) Payload sent from backend

`createEmployee` sends this JSON payload to n8n:

```json
{
  "event": "employee.created",
  "employeeId": 123,
  "organizationId": 1,
  "departmentId": 2,
  "fullName": "John Doe",
  "email": "john@company.com",
  "code": "EMP-001",
  "dateJoined": "2026-05-08T03:30:00.000Z",
  "probationDays": 90,
  "setupLink": "http://localhost:5173/setup-account?employeeId=123&email=john%40company.com",
  "tempPassword": "generated-only-when-password-not-provided"
}
```

## 5) Behavior notes

- If `N8N_ONBOARDING_WEBHOOK_URL` is missing, backend skips webhook call.
- Webhook failure does not block employee creation; it logs an error.
- Password is always saved as hashed value.
